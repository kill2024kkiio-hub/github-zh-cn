GitHub 汉化 · 设置

界面上限由内置词典覆盖；正文内容走下面的翻译服务，结果会本地缓存，重复浏览不再请求。

基本

翻译服务

使用 translate.googleapis.com 的公开端点，无需密钥、无需注册。适合个人日常使用。

任何兼容 /chat/completions 的服务都能用；本地服务把地址填成 http://127.0.0.1:8000/v1 即可。

自定义词条

每行一条，格式 English=中文，会覆盖内置词典的同名词条。例如：

Merge pull request=合并拉取请求
Sponsor=赞助我
Projects=项目管理

维护

缓存存在浏览器本地（chrome.storage.local），清空后正文会重新请求翻译。
